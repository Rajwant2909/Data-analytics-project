# Stage 3 – ANN Predictive Modelling

**Project:** Customer Churn Analysis for a Telecommunications Company  
**Team:** Team 7  
**Responsible Member:** Rajwant Kaur  
**Jira Task:** KAN-184

## Objective

The objective of Stage 3 is to develop and evaluate an Artificial Neural Network (ANN) model to predict customer churn using the preprocessed Telco Customer Churn dataset from Stage 2.

## Predictive Modelling Deliverables

1. ANN Model Architecture Documentation
2. ANN Training Python Script
3. Trained ANN Model
4. Customer Churn Predictions
5. Model Performance Evaluation
6. Model Visualisations

## Model Evaluation

The ANN model will be evaluated using accuracy, precision, recall, F1-score, ROC-AUC and a confusion matrix.

## Expected Outcome

The model will support identification of customers at risk of churn and provide insights for targeted customer retention strategies.
